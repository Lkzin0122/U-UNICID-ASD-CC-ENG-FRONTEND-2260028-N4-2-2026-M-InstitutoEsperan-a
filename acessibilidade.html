Início/Acessibilidade

Um espaço para mais pessoas

Você escolhe
como navegar.

Inclusão começa no acesso. Encontre recursos para adaptar a leitura e orientações para explorar o site no seu ritmo.

Sua leitura, do seu jeito

Mais conforto para ler.

Ajuste o tamanho do texto ou ative o alto contraste. Quando o armazenamento local estiver disponível, suas preferências serão lembradas neste navegador.

Você também pode usar o zoom do próprio navegador. No computador, experimente Ctrl + + para ampliar e Ctrl + 0 para restaurar.

Preferências de leitura

Tamanho do texto

Tamanho do texto: 100%.

Contraste da interface

Inversão de cores

Esses controles ajustam a apresentação. Nenhum dado pessoal é solicitado.

Recursos do site

Pequenos cuidados.
Menos barreiras.

01

Navegação por teclado

Links, botões e campos podem ser alcançados com Tab. Um contorno destaca o item em foco para ajudar você a se localizar.

02

Um atalho para o conteúdo

O primeiro link da página aparece ao receber foco e permite pular o menu, levando você diretamente ao conteúdo principal.

03

Imagens com contexto

Imagens informativas têm descrições alternativas. A galeria inclui legendas e créditos para deixar claro o contexto de cada imagem.

04

Formulários identificados

Cada campo possui um rótulo. O navegador indica campos obrigatórios e verifica o formato do e-mail antes de preparar a mensagem.

05

Mídia com alternativas

Os players têm controles próprios. A página de mídia oferece conteúdo em texto para complementar a experiência com áudio e vídeo.

Explorar os conteúdos →
06

Respeito ao seu ritmo

O layout se adapta a diferentes telas. As transições são reduzidas quando a preferência por menos movimento está ativada no seu dispositivo.

Guia rápido

Explore sem o mouse.

Use os comandos do teclado para percorrer o conteúdo. Os mesmos links estão disponíveis no menu e no rodapé.

Comandos básicos de navegação
TeclaO que faz
TabVai para o próximo link, botão ou campo.
Shift + TabVolta para o item anterior.
EnterAbre o link ou ativa o controle selecionado.
EspaçoAtiva um botão ou abre uma pergunta da lista de dúvidas.
EscFecha a ampliação de imagem da galeria.

Um compromisso contínuo

Acessibilidade se constrói
com escuta.

Este é um projeto acadêmico em evolução. Os recursos descritos não representam uma certificação de conformidade. Testes com diferentes tecnologias assistivas e com pessoas usuárias ajudam a identificar melhorias.

Nossa referência: introdução à acessibilidade da W3C ↗

Encontrou uma dificuldade?

Ao descrever uma barreira, conte em qual página ela aconteceu, qual recurso você tentou usar e, se souber, o navegador ou a tecnologia assistiva utilizada.

O formulário atual permite preparar uma mensagem demonstrativa; ele ainda não a transmite à equipe.
