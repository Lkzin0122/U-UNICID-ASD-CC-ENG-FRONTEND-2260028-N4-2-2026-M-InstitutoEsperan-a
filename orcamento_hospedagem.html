Início/Orçamento de hospedagem

Transparência do projeto

Um lugar na internet.
Uma escolha consciente.

Conheça as opções de hospedagem e domínio pesquisadas para manter o site acessível e com um custo adequado.

01 / Hospedagem

Onde os arquivos do site ficam.

Estas opções permitem publicar as páginas HTML, os estilos e as imagens. Consulta às fontes oficiais em 24/10/2026.

Sugestão para o projeto

GitHub Pages

Grátis no GitHub Free

Hospeda HTML, CSS e JavaScript diretamente de um repositório público. Pode usar o endereço github.io ou um domínio próprio.

Condição: o código precisa estar em um repositório público no plano gratuito. O serviço publica arquivos estáticos.

Fonte: GitHub Docs ↗
Plano Free

Cloudflare Pages

Grátis para arquivos estáticos

As requisições a arquivos estáticos são gratuitas. O plano Free inclui até 500 builds por mês e até 20 mil arquivos por site.

Condição: cada arquivo deve ter no máximo 25 MiB. Funções de servidor têm regras próprias de uso.

Fonte: preços da Cloudflare ↗ Consultar limites do plano ↗
Plano Free

Netlify

US$ 0 por mês

Publicação com rede de distribuição de conteúdo, domínio próprio e SSL. O plano Free trabalha com uma cota de 300 créditos por mês.

Condição: publicações e tráfego consomem créditos. É preciso acompanhar o uso e os limites do plano.

Fonte: preços da Netlify ↗

02 / Domínio

O endereço para encontrar o projeto.

Domínio é uma contratação separada da hospedagem. A comparação considera registros comuns, sem nomes premium e sem verificação de disponibilidade de um nome específico.

03 / Nossa escolha para esta etapa

Publicar de forma simples.
Investir quando fizer sentido.

Uma opção de publicação é GitHub Pages com o endereço gratuito github.io: o site usa arquivos estáticos e pode ser mantido pela equipe em um repositório.

Se um domínio próprio for necessário, a opção .com.br no Registro.br oferece referência de custo em reais: R$ 40,00 por ano na consulta, além da hospedagem gratuita, desde que o nome esteja disponível e os requisitos sejam atendidos.

O que entra nessa conta?

Publicação inicial: hospedagem gratuita e subdomínio fornecido pela plataforma.

Com domínio próprio .com.br: R$ 40,00 por ano na consulta. Este valor não inclui serviços adicionais.

Próxima etapa: envio real de formulários, e-mail institucional e armazenamento de dados precisam de uma solução própria e de novo orçamento.

Sustentabilidade digital: imagens compactas e carregamento de mídia sob demanda reduzem o volume de dados do site. Nenhum fornecedor recebeu uma classificação ambiental sem verificação específica.
